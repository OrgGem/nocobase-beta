# plugin-sub-agent

## Overview
Multi-Agent framework allowing NocoBase AI Employees to spawn and delegate tasks to specialized sub-agents with specific skills.

## Features
- **Agent Spawning**: Allows agents to create ephemeral sub-agents for specific tasks.
- **Skill Isolation**: Keeps main agents lightweight by delegating heavy processing to sub-agents.
- **Parallel Execution**: Sub-agents can perform tasks concurrently.

## Usage
1. Enable the plugin.
2. Configure your primary AI Employee.
3. In the agent settings, enable the "Sub-Agent Framework".
4. Define the conditions under which the main agent should spawn sub-agents.
