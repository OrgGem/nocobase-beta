# plugin-shared-forms

## Overview
Share forms that require authentication and role-based access control.

## Features
- **Secure Form Sharing**: Generate public or private links for data entry forms.
- **Authentication Walls**: Require users to log in before they can submit the form.
- **Role Assignments**: Automatically assign specific roles to users who register via a shared form.

## Usage
1. Enable the plugin.
2. In the UI editor, configure a form block.
3. Click "Share" to generate a unique link.
4. Configure access settings (Public, Requires Login, Specific Roles only).
5. Distribute the link to collect structured data securely.
