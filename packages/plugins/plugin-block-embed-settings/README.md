# plugin-block-embed-settings

## Overview
Embed any plugin settings page as a block on regular pages.

## Features
- **Decentralized Admin UI**: Bring admin settings directly to user-facing pages or custom dashboards.
- **Seamless Integration**: Functions exactly like the native settings view.
- **Role-Based Access**: Adheres to existing NocoBase permissions to ensure only authorized users can view or edit settings.

## Usage
1. Activate the plugin.
2. Navigate to the page where you want to embed settings.
3. Click "Add Block" -> "Plugin Settings Embed".
4. Select the target plugin from the dropdown.
5. The settings form will now render on the page.
