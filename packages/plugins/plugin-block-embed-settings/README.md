# plugin-block-embed-settings

**plugin-block-embed-settings** is a NocoBase plugin that enables users to embed any plugin settings page as a block directly on regular pages.

## Features

- **Block Embedding:** Embed specialized settings interfaces (e.g. AI settings, Knowledge Base config, etc.) natively inside standard User Interface pages.
- **Unified Experience:** Reduces the need for users to navigate to the NocoBase admin settings area, bringing the power of plugin configurations right into customized workspaces.
- **Easy Configuration:** Works out-of-the-box leveraging the NocoBase Schema component system.

## Installation

This plugin is designed to work within the NocoBase ecosystem. Install it via the NocoBase plugin manager or place it in the `packages/plugins/` directory and build.

## Usage

1. Enable the plugin from the Plugin Manager.
2. Go to any page in your NocoBase application.
3. Open the UI Editor and add a new Block.
4. Select the **Embed Settings** block and configure the target plugin settings to render.
