# plugin-data-source-elasticsearch

## Overview
Connect to Elasticsearch servers and browse indices as collections with full CRUD support.

## Features
- **External Datasource**: Seamlessly integrates Elasticsearch into NocoBase as a native datasource.
- **Index to Collection Mapping**: Automatically maps ES indices to NocoBase collections and ES mappings to NocoBase fields.
- **CRUD & Search**: Read, write, update, and perform advanced searches directly from the NocoBase UI.

## Usage
1. Enable the plugin.
2. Go to `Data Sources` in NocoBase settings.
3. Click "Add Data Source" and choose "Elasticsearch".
4. Enter your connection details (URL, Auth credentials).
5. Sync the collections. You can now use these Elasticsearch collections in your tables, forms, and blocks.
