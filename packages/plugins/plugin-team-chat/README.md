# plugin-team-chat

## Overview
Full-featured team chat with channels, direct messages, threads, reactions, and realtime message delivery.

## Features
- **Realtime Messaging**: Instant message delivery powered by WebSockets.
- **Channels & DMs**: Create public/private channels or send direct messages to colleagues.
- **Rich Chat Features**: Supports threads, emoji reactions, and file attachments.

## Usage
1. Enable the plugin (requires `plugin-comm-core`).
2. Navigate to the Team Chat app interface.
3. Create a new channel or start a direct message.
4. Chat in real-time with other logged-in NocoBase users.
