# plugin-skill-hub

## Overview
Manage and execute Python/Node.js skills in sandbox on worker server for AI Employees.

## Features
- **Multi-Language Support**: Write custom business logic in Python or Node.js.
- **Sandboxed Execution**: Runs scripts securely in isolated worker environments.
- **AI Tool Integration**: Exposes these scripts as "Skills" or tools that AI Employees can call autonomously.

## Usage
1. Enable the plugin.
2. Navigate to "Skill Hub" in the admin dashboard.
3. Create a new skill, select the runtime (Python or Node.js), and write your code.
4. Define the input parameters and expected output format.
5. Assign this skill to an AI Employee so it can be executed during chat interactions.
