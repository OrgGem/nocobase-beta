# plugin-user-memory

## Overview
User Memory plugin - synthesizes chat history into persistent user profiles for personalized AI responses.

## Features
- **Persistent Memory**: AI remembers user preferences, past instructions, and context across sessions.
- **Memory Synthesis**: Periodically summarizes raw chat logs into a compact "User Profile" to save tokens.
- **Privacy Controls**: Users can view and delete memories the AI has saved about them.

## Usage
1. Enable the plugin.
2. In the AI Settings, toggle "Enable User Memory".
3. When users chat with AI Employees, the AI will naturally learn and store their preferences.
4. Users can go to their Profile -> AI Memory to review what the system knows about them.
