# plugin-skill-pptx-advanced

## Overview
Advanced SVG-to-PPTX presentation generation skill for Skill Hub.

## Features
- **Presentation Generation**: Converts SVG or structured data into native PowerPoint (`.pptx`) files.
- **Skill Hub Add-on**: Built to be executed securely within the Skill Hub sandbox.
- **AI Integration**: AI Employees can use this skill to generate slide decks based on user prompts.

## Usage
1. Ensure both `plugin-skill-hub` and this plugin are enabled.
2. The PPTX generation script will be automatically registered in the Skill Hub.
3. Grant an AI Employee access to the "Generate PPTX" tool.
4. In chat, ask the AI to "Create a presentation about our Q3 sales."
