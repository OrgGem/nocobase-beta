# plugin-cluster-manager

## Overview
Monitor cluster nodes, async tasks, workflow executions, event queues, locks, caches, and Redis metrics.

## Features
- **Cluster Dashboard**: Realtime view of all active NocoBase nodes and workers.
- **Queue Management**: Inspect active, pending, and failed background jobs (BullMQ).
- **Redis Metrics**: Monitor memory usage, hit rates, and connected clients.

## Usage
1. Enable the plugin.
2. Only accessible to Super Admins.
3. Navigate to System Settings -> Worker Monitor.
4. Use the dashboard to troubleshoot performance issues, retry failed background tasks, or clear caches.
