# jira.js API navigation

`Version3Client` and `Version2Client` cover the Jira platform APIs; `AgileClient` covers boards/sprints; `ServiceDeskClient` covers portals/requests. Each client exposes grouped properties such as `issues`, `issueSearch`, `projects`, `users`, and `workflows`. Run `list`, then inspect installed `.d.ts` files or the package documentation for exact parameter types.
